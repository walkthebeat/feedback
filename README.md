# walkthebeat feedback

Tell us what broke, what confused you, and what your agent could not see. beat is in alpha, and this is how it gets better.

- **Something is wrong:** [open an issue](https://github.com/walkthebeat/feedback/issues/new/choose).
- **A question or an idea:** [start a discussion](https://github.com/walkthebeat/feedback/discussions).

**This repository is public.** Please do not paste hostnames, configuration, answers from your hosts, transcripts or
secrets here. A summary, the versions and a survey id are enough to start: we can ask for more privately.

Docs: [walkthebeat.ai/docs](https://walkthebeat.ai/docs).
